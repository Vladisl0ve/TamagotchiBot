# Игровая логика

Числа и enum’ы живут в [`TamagotchiBot/UserExtensions/Constants.cs`](../TamagotchiBot/UserExtensions/Constants.cs). Состояние питомца и игрока — в Mongo ([модель данных](data-model.md)).

## Сущности

| Сущность | Класс | Что хранит |
|----------|-------|------------|
| Питомец | `Pet` | Статы, статус, работа, учёба, автокорм |
| Игрок | `User` | Культура, Gold/Diamonds, VIP, реферал, флаги мини-игр |
| Мета | `MetaUser` | Переименование, VIP-подтверждения, дуэли, история LLM, бонус-коды |

Один пользователь — один питомец. Инвентаря предметов нет: еда покупается и сразу съедается. «Имущество» — валюты, заряды автокорма и список `OwnedPetTypes`.

## Типы и статусы питомца

`Constants.PetType`: Cat, Dog, Mouse, Fox, Panda, Monkey; премиум Tiger / Lion.

`Constants.CurrentStatus`:

- `Active` — обычное состояние
- `Sleeping` — сон, восстанавливает усталость
- `Working` — работа по таймеру
- `Studying` — учёба по этапам

Работа: `JobType` (PC, листовки, McDonalds, визажист, доставка, бухгалтер, инженер, пилот, ювелир). Ювелир завязан на VIP и специальную школу.

Учёба: `EducationLevel` (начальная → средняя → старшая → завершённая → спец. ювелир). Число этапов — `Constants.Education`. VIP ускоряет учёбу (`Factors.EducationCoefFasterVIPProc`).

## Статы

| Поле | Смысл | Типичный диапазон |
|------|--------|-------------------|
| `HP` | Здоровье; падает при нулевой сытости | 0–100 |
| `Satiety` | Сытость | 0–100 |
| `Joy` | Радость | растёт от игр, падает со временем и от работы |
| `Fatigue` | Усталость | растёт со временем, снимается сном |
| `Hygiene` | Гигиена | душ / зубы / «уборка» |
| `EXP` / `Level` | Сезонный опыт и уровень | `ExpToLvl = 50` EXP на уровень |
| `LevelAllGame` | Накопленный уровень за всё время | не сбрасывается сезонной джобой так же, как EXP |
| `MPSatiety` | Сытость от группового кормления | учитывается при decay, затем обнуляется |
| `IsGone` | Питомец «ушёл» (смерть) | воскрешение за золото |

## Ленивый decay

Статы **не** крутятся фоновой джобой. При каждом релевантном апдейте `CreatorController.UpdateIndicators()` считает минуты с `Pet.LastUpdateTime` и применяет `Constants.Factors` (в минуту):

| Фактор | Значение | Эффект |
|--------|----------|--------|
| `StarvingFactor` | 0.08 | −сытость; при 0 сытости падает HP |
| `JoyFactor` | 0.2 | −радость |
| `HygieneFactor` | 0.1 | −гигиена |
| `FatigueFactor` | 0.19 | +усталость |
| `ExpFactor` | 1 | EXP за минуты активности |
| `RestFactor` | 10 | восстановление при сне |

Дополнительно при том же вызове:

- завершение сна / работы / этапа учёбы по таймерам;
- истечение VIP (`VIPStartTime + VIPLongDays`).

Если HP дошло до 0 — сценарий смерти (`AfterDeath`). Воскрешение: `Costs.ResurrectPet` (1000 золота).

## Уход

Команды меню (плюс локализованные кнопки клавиатуры) обрабатывает `MenuController`:

| Команда | Что делает |
|---------|------------|
| `/pet` | Карточка питомца |
| `/kitchen` | Еда за золото (`Costs` + `FoodFactors`) |
| `/sleep` | Сон (`TimesToWait.SleepToWait` = 2 мин) |
| `/bathroom` | Гигиена (`HygieneFactors`) |
| `/hospital` | Лечение |
| `/gameroom` | Мини-игры |
| `/work` | Работа, доступ зависит от образования |
| `/education` | Школа по этапам |
| `/reward` | Ежедневная награда (250 золота, КД 24 ч) |
| `/farm` | Автокорм |
| `/referal` | Реферальная ссылка |
| `/ranks` | Таблицы лидеров |
| `/rename` | Переименование (500 золота) |
| `/language` | Язык |
| `/menu`, `/help`, `/changelog` | Меню / справка / новости |

Еда (золото → эффект): хлеб 50 / +50 сытости, яблоко 5 / +5 и +1 HP, леденец 1 / +1, шоколад 4 / +2 сытости и −1 усталость, кофе 10 / +2 сытости и −5 усталости, молоко 10 / +10 сытости и +2 HP.

## Экономика

**Gold** — основная валюта (еда, игры, работа, переименование, смена типа, воскрешение, дуэли).

**Diamonds** — премиум: VIP на 7 дней (`Costs.VIP7DaysDiamonds` = 100), заряды автокорма (`AutoFeedCostDiamonds` = 100). Покупка через Telegram Stars (`Constants.PaymentItems`: пакеты 10/50/100/500 Stars → 10/55/120/650 алмазов).

Смена типа: обычные 5000 золота; Tiger 500000; Lion 1000000.

Реферал: пригласившему +1000 золота и +20 алмазов (`Rewards.ReferalAdded*`).

Сезонный топ-10 по уровню награждается в `ResetAllExpJob` (`GoldForTopExpRanking`).

## Мини-игры

Вход из `/gameroom`. Пока флаг `User.IsInAppleGame` / `IsInTicTacToeGame` / `IsInHangmanGame` включён, `UpdateHandler` отдаёт апдейты соответствующему контроллеру, а не меню.

| Игра | Стоимость | Радость / усталость |
|------|-----------|---------------------|
| Яблоки | 20 | +20 / +20 |
| Кости | 5 | +10 / +5 |
| Карты | (через меню) | +20 / +20 |
| Крестики-нолики | 25 | +20 / +5 |
| Виселица | 40 | +20 / +5 |

Виселица рисует картинку через SkiaSharp (`HangmanImageGenerator`), словарь — `Resources/Hangman_dicts/russian.txt`.

## Мультиплеер (группы)

`MultiplayerController`, команды `Constants.CommandsMP`:

- `show_pet` — показать питомца;
- `start_duel` — дуэль (ставка 100 золота, награда победителю 150, КД 5 мин, таймаут той же длительности в `DuelTimeoutJob`);
- `feed_pet` — покормить чужого питомца (20 золота, `MPFeedFactor` = 100, КД 6 ч);
- `ranks` — ранги чата.

## Прочие фичи

- **VIP** — ускоренная учёба, ювелирная работа, бонусы; длительность в днях (`VIPLongDays`).
- **Автокорм** — `IsAutoFeedEnabled` + `AutoFeedCharges`; Quartz каждые 4 часа кормит на +100 сытости и списывает заряд.
- **Случайные события** — `RandomEventService` / `RandomEventJob` (не шлёт ночью 20:00–04:00 UTC).
- **Чат с питомцем** — Gemini HTTP (`ServiceInfo.GeminiApiKey`, промпт `Resources/Prompts/GeminiPetRoleplay.txt`) и устаревший путь OpenAI.
- **Бонус-коды** — `BonusCode` / `BonusType.VIP7Days`.
- **Subgram** — спонсорские задания для пользователей старше суток (пропускается в DEBUG/STAGING и для `uk`/`be`).
- **Реклама Gramads** — `SendGramadsPostToChat` после игровых действий.

Баланс и тайминги меняются только константами в `Constants.cs`, не конфигом.
